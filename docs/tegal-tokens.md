# TEGAL tokens

Canonical contract: [sovereign-ecosystem/docs/contracts/TEGAL-TOKENS.md](https://github.com/Shootle/sovereign-ecosystem/blob/main/docs/contracts/TEGAL-TOKENS.md) (also mirrored in monorepo checkouts at `docs/contracts/TEGAL-TOKENS.md`).

Summary:

- **TEGAL** — native governance and utility token; micro-denom **uteg**
- **Never pre-mined** — issuance only via block creation (impact work), exchange purchase, and DAO-governed burn technology
- **Block rewards** — tied to verified node operator work and DAO-approved ecosystem participation incentives
- **Transynths (tX*)** — separate provenance impact assets; not TEGAL

See [voixcoin.md](./voixcoin.md) for **Voixcoin** (PA-collateralized stablecoin on the custodianless Greenledger).
