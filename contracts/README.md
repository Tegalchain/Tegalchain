# Contracts Workspace

- tXb/ (biodiversity Transynth)
- tXw/ (water Transynth)
- tXs/ (soil Transynth)
- tXi/ (I-REC Transynth)
- token-factory/
- por-evidence-registry/
- poref-validation/
- impact-market/
- token-retirement/
- validator-slashing/
- reward-distribution/

See contracts/DEVELOPMENT.md for setup and build instructions.
