# Voixcoin

Canonical contract: [sovereign-ecosystem/docs/contracts/VOIXCOIN.md](https://github.com/Shootle/sovereign-ecosystem/blob/main/docs/contracts/VOIXCOIN.md).

Summary:

- **Voixcoin** — Tegalchain stablecoin; minted **only** by collateralizing **PA (Provenance Assets)** in a secured **non-custodial** Greenledger vault
- **Custodianless** — no off-chain custodian; PA lock/unlock is on-chain under protocol + Auditrail rules
- **PA** — primarily **Transynths (tX***)** with verified PoRE/Auditrail evidence
- **Redeem** — burn Voixcoin to unlock PA per DAO collateral parameters

See also [tegal-tokens.md](./tegal-tokens.md) for TEGAL / uteg.
